# Documentation Archive

이 디렉터리는 현재 truth-source가 아닌 historical/non-canonical 문서를 보존하기 위한 archive다.

## Why These Docs Are Archived

- old blueprint / implementation plan / rulebook / prompt / reference 문서가 current canonical chain과 섞여 stale truth-source처럼 보이던 상태를 해소하기 위해서다.
- 현재 canonical docs는 `Docs/Architecture`와 `Docs/Testing`의 active set으로 닫혀 있다.
- archived docs는 historical value는 유지하되, active entrypoint에서는 분리한다.
